# Student Counseling Assistant — Project Report

## 1. Introduction

Students may experience academic pressure, difficulty planning their studies, uncertainty about career choices, and stress during examinations. The Student Counseling Assistant is a Python-based chatbot prototype designed to provide basic educational guidance and supportive suggestions through a simple graphical user interface.

## 2. Objectives

- Develop an interactive chatbot for student guidance.
- Provide general study strategies and academic support.
- Offer career exploration suggestions.
- Respond supportively to messages about stress and motivation.
- Implement basic text preprocessing, intent detection, and sentiment analysis.
- Provide conversation summaries and a clear-chat option.

## 3. Technologies Used

- **Python:** Implements the chatbot logic.
- **Tkinter:** Creates the graphical user interface.
- **Regular expressions:** Preprocesses user messages into text tokens.
- **Keyword-based intent detection:** Identifies the likely topic of a message.
- **Word-based sentiment analysis:** Estimates whether a message has positive, negative, or neutral sentiment.

The application uses built-in Python functionality and is designed to run locally without an internet connection.

## 4. System Methodology

The application follows these steps:

1. The user enters a message in the chatbot window.
2. The application preprocesses the message.
3. The intent detection component checks keywords to identify the topic.
4. The sentiment analysis component estimates the message's sentiment using word matching.
5. The response component selects a suitable predefined response.
6. The chatbot displays its response and the text-analysis result.
7. The user can view a conversation summary or clear the conversation.

## 5. Main Features

### 5.1 Student Guidance Chatbot
Provides predefined responses for greetings, study strategies, academic concerns, career exploration, stress management, motivation, and related topics.

### 5.2 Sentiment Analysis
Uses a simple word-based approach to classify messages as positive, negative, or neutral. The results are estimates rather than a reliable measurement of a person's emotional state.

### 5.3 Intent Detection
Uses keyword matching to identify the likely topic of a user's message.

### 5.4 Conversation Summary
Displays the number of analysed messages and the most frequently detected topics.

### 5.5 Clear Chat
Allows users to clear the current conversation and start a new interaction.

## 6. Testing and Results

The following interactions were tested during development:

| Test Input | Expected Behaviour | Observed Result |
|---|---|---|
| `hi` | Display a greeting | Greeting response displayed |
| `I'm stressed about exams` | Offer supportive stress guidance | Stress response and Negative sentiment displayed |
| `Help me make a study plan` | Provide study suggestions | Study response displayed |
| `What career should I explore?` | Provide career exploration guidance | Career response displayed |
| Conversation Summary | Show analysed messages and detected topics | Summary displayed |
| Clear Chat | Clear the conversation | Chat-cleared message displayed |

These tests indicate that the main chatbot functions work for the tested inputs. They do not establish that the system understands every possible message.

## 7. Limitations

- Responses are predefined rather than generated by a trained language model.
- Intent detection depends on the configured keywords.
- Word-based sentiment analysis can misinterpret context, sarcasm, and complex emotions.
- The application does not provide professional counselling, medical advice, or mental health diagnoses.

## 8. Future Enhancements

- Integrate a more advanced natural language processing model.
- Improve intent classification and sentiment analysis.
- Add personalised study-planning functionality.
- Support additional languages.
- Expand career exploration resources and guidance.

## 9. Conclusion

The Student Counseling Assistant demonstrates how Python and a graphical interface can be used to build a basic student-support chatbot. It combines predefined guidance, keyword-based intent detection, simple sentiment analysis, and conversation management in an offline application. The prototype provides a foundation for future improvements in educational support systems.

## 10. Responsible Use

This application is an educational prototype and is not a replacement for a qualified counsellor or mental health professional. Students experiencing serious distress should seek help from a trusted person or qualified professional. In an emergency, they should contact local emergency services.
