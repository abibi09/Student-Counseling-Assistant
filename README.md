# Student Counseling Assistant

## Project Overview
The Student Counseling Assistant is a Python-based chatbot designed to provide students with basic educational guidance, study strategies, career exploration suggestions, motivation, and stress-management tips.

The application uses simple natural language processing techniques, keyword-based intent detection, and word-based sentiment analysis to generate relevant responses.

## Features
- **Interactive Chatbot:** Communicate with the assistant through a graphical interface.
- **Study Guidance:** Receive practical study tips and planning suggestions.
- **Academic Support:** Get general guidance for academic challenges.
- **Career Exploration:** Discover ways to explore career interests and skills.
- **Stress Management:** Receive general stress-management and motivation suggestions.
- **Sentiment Analysis:** Estimate whether a message expresses positive, negative, or neutral sentiment.
- **Intent Detection:** Identify topics such as greetings, studying, careers, and stress.
- **Conversation Summary:** Review message counts and detected topics.
- **Clear Chat:** Clear the current conversation and start again.
- **Offline Operation:** Run the application locally without requiring an internet connection.

## Technologies Used
- Python 3
- Tkinter for the graphical user interface
- Regular expressions for text preprocessing
- Rule-based keyword matching for intent detection
- A simple word-based sentiment analysis approach

## How to Run

1. Install Python 3 on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the integrated terminal.
4. Run the following command:

```bash
python app.py
```

5. The Student Counseling Assistant window will open. Type a message and click Send to interact with the chatbot.

Tkinter is included with many standard Python installations. No additional Python packages are required if Tkinter is available.

## How It Works
1. The user enters a message.
2. The application preprocesses the text.
3. Keyword matching identifies the likely topic or intent.
4. A basic sentiment analyzer estimates the message's sentiment.
5. The chatbot selects a suitable predefined response.
6. The application displays the response and analysis information.
7. Users can view a conversation summary or clear the chat.

## Responsible Use
This project is an educational prototype. It is not a substitute for a qualified counselor, psychologist, or other mental health professional. Sentiment analysis is based on simple word matching and may be inaccurate. Students experiencing serious emotional distress should seek support from a trusted person or qualified professional. In an emergency, contact local emergency services.

## Limitations
- Responses are based on predefined rules and are not generated by a trained AI language model.
- Sentiment analysis may misunderstand context, sarcasm, or complex emotions.
- Intent detection depends on the keywords included in the application.
- The assistant does not provide medical diagnoses or professional mental health treatment.
